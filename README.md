# 🗼 Tower Box

A colorful stacking game with dynamic skies — sun, clouds, rain, rainbows, moon & stars!

## 🎮 How to Play
- **Tap / Click / Spacebar** to drop the moving box
- Stack as high as you can — perfect alignment grows your tower & gives combo bonuses
- Watch the world change as you climb: sunny → cloudy/rainy → sunset → night → space

## 🌐 Deploy to Cloudflare Pages

1. Push this folder to a GitHub repository
2. Go to [Cloudflare Pages](https://pages.cloudflare.com)
3. **Create a project → Connect to Git → Select your repo**
4. Build settings:
   - Build command: *(leave blank)*
   - Build output directory: `/`
5. Click **Save and Deploy** ✅

Also works on **Netlify**, **Vercel**, **GitHub Pages**, or any static host — just upload all files.

## 📁 Files
- `index.html` — entry point
- `style.css` — responsive styles (mobile + desktop)
- `game.js` — game engine (Canvas + Web Audio)
- `assets/logo.png` — game logo

## 🔊 Sound
All sound effects are **generated procedurally** with the Web Audio API — no audio files needed, instant load!
